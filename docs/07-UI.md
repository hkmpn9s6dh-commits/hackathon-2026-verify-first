# UI 说明（07-UI）

## 1. 风格预设

**工业现场 HUD**：深石墨底（#0a0d10 / #12181d）+ 青蓝信号色（#58d5f0）+ 三态语义色（通过 #3ddc84、复核 #ffb02e、拦截 #ff5f6d）。中文 14px 基准，数据用等宽数字（`tabular-nums`）。不做玻璃拟态与花哨渐变；金属感来自块面与细边框，不来自高光。

## 2. 尺子（学哪一点）

| 参考 | 学什么 |
| --- | --- |
| 工业 HMI / SCADA 操作台 | 一个屏幕只有一个当前动作；状态灯与结论永远在同一位置 |
| 头戴设备 HUD（航空/体育） | 信息贴在视野边缘，中央留空；单行提示，不超过两行 |
| 医疗设备核对界面（WHO 手术安全核查） | 逐项打勾、不可跳过、签字留痕 |
| 往届 AR 作业类作品 | 避免把手机 UI 直接投到镜片；一屏一结论 |

## 3. 记忆点

**红框落在错误的那台柜子上，而不是弹一个对话框。** 判定结果贴在它判定的那个物件上（包围框 + 一行标签），作业人不用读文字就知道「是这台不对」。

## 4. 主屏规格

- 16:10 第一视角视口，四角 HUD 括号 + 中央准星 + 底部单行提示条。
- 右侧三块：当前判定（大字）、作业步骤（5 条，状态色）、事件留痕（表格，滚动）。
- 底部步骤条与右侧步骤列同步，避免「不知道现在第几步」。
- 拦截时出现琥珀色处置卡，只有一个主按钮；复核时两个按钮（确认/否定）。
- 报告用浅色纸面（#f6f4ef），与现场界面形成「工作态/归档态」区分。

## 5. 已知弱点（下一轮改）

1. 手套与验电器的绘制是示意，真机上应由真实画面承担；原型的价值在判定链路，不在美术。
2. 事件表在 1440 宽下可见 5–6 行，长会话会滚动；下一步加「只看异常」筛选。
3. 步骤条与右侧步骤列信息重复，1440 以下可合并；保留是为了大屏演示时后排可见。
4. 未在镜片上验证字号与对比度——`未验证（待样机）`。
